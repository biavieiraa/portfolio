#  Portfólio - Beatriz Vieira

Esse é o site do meu portfólio pessoal. No site, mostrei um pouco sobre mim, minhas habilidades e alguns projetos que já desenvolvi. Ele foi criado como projeto prático para a disciplina de Introdução à Computação, aplicando conceitos reais de desenvolvimento front-end.

 **[Clique aqui para ver o site online](https://biavieiraa.github.io/portfolio/)**

---

## Estrutura do Site

O projeto foi dividido em páginas específicas para deixar a navegação simples e organizada:
* **Home (`index.html`):** Minha apresentação inicial e resumo das minhas principais habilidades.
* **Projetos (`projetos.html`):** Onde mostro meus trabalhos acadêmicos e práticos, incluindo o Artefato do Projeto 1.
* **Contato (`contato.html`):** Página com meus links de redes sociais e canais para falar comigo.

---

## Tecnologias que usei

Fiz o site do zero usando as tecnologias básicas da web, focando em deixar o código limpo e organizado:

* **HTML5:** Usei tags semânticas (como `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) para garantir que o site ficasse bem estruturado e acessível.
* **CSS3:** Organizei o layout usando **Flexbox e Grid** para que tudo ficasse alinhado do jeito certo, garantindo que o design seja totalmente responsivo (adaptável para celular e computador).
* **JavaScript:** Coloquei funções em JS para resolver a parte interativa do site, como o funcionamento do menu responsivo.
