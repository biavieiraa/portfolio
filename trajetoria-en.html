Recife Alerta

Developed for the Projects 1 course at Cesar School, this project is a board game adaptation of the classic "Mafia" (Cidade Dorme) with a strong focus on accessibility. Using Arduino integration, we adapted the game to include hearing-impaired players: traditional voice commands and secret actions were entirely replaced by tactile vibration mechanisms. Beyond merging code and hardware, this is technology applied to break down barriers and build a truly inclusive entertainment experience.

HYROX Planner

Developed as a team project for the Programming Fundamentals 1 course, the HYROX Planner is a CLI application built entirely in Python. The system enables users to manage workout routines and log performance metrics for specific HYROX events, such as SkiErg, Sled Push, and Burpee Broad Jumps. The application also features competition planning with an automatic event countdown tool, along with persistent data storage handled through text files.
